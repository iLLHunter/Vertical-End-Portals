# Vertical End Portals

A NeoForge 1.21.1 mod that adds a vertical end portal frame block.

Build a frame with the same 3-block-per-side layout as a vanilla End Portal. The face you place the block against determines which side displays the eye. Aim outward from the intended portal center while placing each side so the green markers point inward.

- 3 blocks on the bottom facing up
- 3 blocks on the top facing down
- 3 blocks on each side facing inward

Fill every frame with an Eye of Ender. When the 12-frame ring is complete, the 3x3 center becomes a vertical End Portal surface with vanilla teleport behavior.

Craft one Vertical End Portal Frame shapelessly from one vanilla End Portal Frame and one Lever.

Build with:

```powershell
.\gradlew.bat build
```

The mod jar is written to `build/libs`.
